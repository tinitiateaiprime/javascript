# How to Run the Examples

This page explains the commands before you use them.

## What Is a Command?
A command is text you type in a terminal. The terminal asks your computer to do something.

## What Is Node.js?
Node.js runs JavaScript outside the browser. In this folder, every `index.js` file can be tested with Node.js.

## Run One Lesson
First open a terminal in the `javascript` folder. Then run these commands:

```bash
cd code/06_js_variables
node index.js
```

What the commands mean:
- `cd` means change directory.
- `code/06_js_variables` is the folder for the variables lesson.
- `node index.js` tells Node.js to run the JavaScript file named `index.js`.

## Go Back to the Main Folder
If you are inside a lesson folder, this command moves back two folders:

```bash
cd ../..
```

## Run a Different Lesson
Use the same pattern with another folder:

```bash
cd code/20_js_arrays
node index.js
```

## View a Lesson in the Browser
```text
Open the lesson's index.html file in VS Code.
Right-click the file.
Choose "Open with Live Preview".
```

Use Live Preview for browser lessons because it gives the page a local address and avoids beginner browser-file problems.
