# Code Examples

Each folder contains a small JavaScript example and an HTML page for browser practice.

## How to Use a Code Folder
1. Read the matching Markdown file in `md/`.
2. Open the matching folder in `code/`.
3. Run `node index.js` from inside that folder.
4. Open `index.html` with VS Code Live Preview for the browser version.
